# CodeScope

> Understand your codebase.

CodeScope is a local-first developer tool for exploring and understanding software repositories.

## Status

🚧 Early development — v0.1

## Planned features

- Repository scanning
- Language detection
- File and line statistics
- Project explorer
- TODO/FIXME detection
- Git insights
- Dependency visualization
- Code hotspots

## Philosophy

Your source code stays on your machine.
